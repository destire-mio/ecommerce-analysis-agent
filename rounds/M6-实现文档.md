## 0. 目标与硬约束

**目标**：用户能在界面里：输入问题 → 看结论 → 点"查看依据"看证据（结构化）→（有图时）看图表。

**硬约束（AGENTS.md 第 4 轮）**：**不新增任何业务功能**，只把现有 Runtime 搬进产品。
`agent_loop.run_agent(...)` 是唯一 Runtime 入口，**不得改它的业务逻辑**。

## 1. 技术栈（已讨论定案）

| 层 | 选型 |
|---|---|
| 后端 | **Flask**（同步，直接调同步的 `run_agent`） |
| 前端 | **Vue 3**（Vite 构建） |
| 图表 | **ECharts**（npm 本地安装，非 CDN） |
| 交互 | **多轮**：前端记住 `session_id`，追问带上 |
| 托管 | `npm run build` 出 `dist/`，Flask 托管 `dist/` + 提供接口 |
| 冒烟 | **轻**：启动脚本 + 冒烟脚本（不打包桌面 App） |

---

## 2. 架构（链路：UI → HTTP → Runtime → Tool → UI）

```
浏览器(Vue)  --POST /ask {question, session_id?}-->  Flask(web/server.py)
                                                         │ 调
                                                         ▼
                                              agent_loop.run_agent(...)
                                                         │（内部调工具/planner/engine/MCP）
                                                         ▼
浏览器 <-- {answer, evidence:[...], charts:[...], session_id, run_id} -- Flask
```

---

## 3. 交付物

### 3.1 后端 `web/server.py`（Flask）
- `POST /ask`：body `{question, session_id?}` → 调 `run_agent(question, bench="ecommerce", db_id="ecommerce", session_id=session_id)` → 返回：
  ```json
  {
    "answer": "<结论纯文字>",
    "evidence": [ {"qn":"Q1", "tool":"query_metrics", "detail": "<sql/args>", "n_rows": 2}, ... ],
    "charts": [ <若执行的工具是 chart, 取其 option> ],
    "session_id": "...", "run_id": "...", "status": "ok"
  }
  ```
  - `evidence` 从 `result["executions"]` 结构化成列表（Qn / 工具 / SQL或参数 / 行数）
  - `charts`：扫描 `executions`，凡 `tool=="chart"` 的取其返回的 `option` 放进数组（M5-S4 的 chart 工具产出的 ECharts option）
- `GET /`：返回 `dist/index.html`；`GET /assets/*` 返回 `dist/` 静态资源
- 线程：`Flask(threaded=True)`；**长请求**（agent 可能跑几十秒到几分钟）→ 前端加 loading，不要设短超时
- `ask_user`：服务端非 tty，自动走批跑分支（返回 unavailable，agent 用默认口径）——**正常**，不用特殊处理

### 3.2 前端 `frontend/`（Vue 3 + Vite）
- 一个页面：
  - 输入框 + 发送按钮（loading 态）
  - **结论区**：显示 `answer`
  - **查看依据**（可折叠/展开）：结构化列表，每项 `Qn · 工具 · SQL/参数 · 行数`，可点开细节
  - **图表区**：遍历 `charts` 渲染 ECharts（`echarts.init(el).setOption(opt)`）
- 多轮：把后端返回的 `session_id` 存组件状态，后续请求带上
- 构建输出目录设为 `../dist`（或构建后 `cp -r dist ../`，由执行 agent 定，最终 Flask 能托管即可）

### 3.3 启动脚本 `web/run.py`
- 起 Flask（默认端口如 8000），自动打开浏览器（`webbrowser.open`）
- 若 `dist/` 不存在则提示先 `npm run build`

### 3.4 冒烟脚本 `tools/run_smoke.py`
- 启服务 → `POST /ask` 问“近7天商品支付金额是多少？” → 断言返回 `status=="ok"` 且 `answer` 含 `800000`

### 3.5 发布门禁 `tools/run_release_gate.py`
- 汇总跑：`run_semantic_acceptance.py`（11/11）+ 各 golden + `run_smoke.py` → 全绿打印清单
