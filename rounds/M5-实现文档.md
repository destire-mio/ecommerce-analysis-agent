## S4 · 图表（待讨论）

**决策**：**不装 matplotlib**。图表输出 **Vega-Lite 风格 JSON 配置**（`reports/<id>.chart.json`），由前端（M6 UI）或用户自行渲染。

**改动**
1. 新工具 `chart(spec, chart_type, x, y)`（`agent_loop.py` dispatch）：
   - `spec` = 一个 QuerySpec（走现有 planner/engine 取数）
   - `chart_type` ∈ `bar|line`
   - `x`/`y` = 用结果里的哪列做 x 轴 / y 轴（x 为维度，y 为指标列）
   - 产出：`{"$schema": "https://vega-lite...", "data": {"values": [...]}, "mark": {...}, "encoding": {...}}`
   - 落盘 `reports/<逐字时间戳>.chart.json`，返回 `{status, path, spec}`
2. tool schema 加 `chart`；材料包提示："要图时用 chart(基于 query_metrics 的结果)"
3. 复用：取数完全走 `query_metrics` 的 planner/engine；chart 只做"结果→配置"的确定性转换

**验收**
